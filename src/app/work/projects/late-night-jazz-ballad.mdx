## Overview

Created a complete AI music production pipeline — from prompt engineering to distribution — for **Late Night Jazz Ballad**, an instrumental jazz piano project. The system leverages Suno AI for generation and a custom-built Prompt Factory tool for systematic, high-quality batch production.

## The Prompt Factory

The centerpiece of the pipeline is a custom web tool built in HTML/JavaScript that transforms music production from one-off experiments into a repeatable system:

- **6 prompt templates** optimized for different jazz subgenres (ballads, bossa nova, late-night ambient, etc.)
- **Batch processing**: Generate multiple prompt variations simultaneously with controlled randomization of parameters like tempo, mood, and instrumentation
- **Quality scoring**: Built-in criteria to evaluate generated tracks before they enter the production pipeline

## Production Pipeline

1. **Prompt generation**: Prompt Factory creates optimized prompts with specific musical parameters
2. **AI generation**: Suno AI produces raw tracks from the engineered prompts
3. **Post-processing**: Audio cleanup and formatting using ffmpeg for consistent output quality
4. **Distribution**: Automated upload pipeline to DistroKid for distribution across Spotify, Apple Music, and other streaming platforms

## Catalog

Over **20+ tracks** produced and distributed across major streaming platforms. The project demonstrates that AI music production at scale requires engineering discipline — not just creative prompting.

## Technologies Used

- **Suno AI** — Music generation engine
- **JavaScript/HTML** — Prompt Factory tool
- **ffmpeg** — Audio processing and format conversion
- **DistroKid** — Distribution to streaming platforms
